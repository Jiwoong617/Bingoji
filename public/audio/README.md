# Bingoji audio files

`npm run generate:audio`로 생성한 Bingoji 전용 절차적 음원이다. 외부 음원 샘플을 사용하지 않았다.

## BGM

- `main-bgm.wav`
- `battle-bgm.wav`

## SFX

- `touch.wav`
- `placement.wav` — 플레이어와 적 배치 공용
- `draw.wav`
- `discard.wav`
- `bingo.wav`
- `attack.wav`
- `recovery.wav` — 회복과 방어막 공용
- `rest.wav`
- `victory.wav`
- `defeat.wav`
