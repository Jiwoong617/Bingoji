# 🎲 Bingoji

**하나의 5×5 보드를 적과 나눠 쓰는 Emoji 빙고 로그라이크.**

빙고판은 하나뿐입니다. 내가 놓은 칸도, 적이 놓은 칸도 같은 보드에 쌓입니다.
**마지막 빈칸을 채운 쪽이 그 라인 전체의 주인**이 되고, 라인에 놓인 Emoji 5개의 능력을 전부 자기 편에서 사용합니다.

> 적이 완성 직전까지 쌓아 올린 라인을, 마지막 한 칸으로 통째로 빼앗을 수 있습니다.
> 물론 반대도 마찬가지입니다.

---

## 🎮 게임 방법

### 한 턴에 하는 일

```
Pool에서 Emoji 3개 Draw  →  빈칸 선택  →  Draw한 Emoji 중 하나 배치  →  효과 발동  →  적 턴
```

1. 턴이 시작되면 내 Emoji **Pool 전체에서 무작위로 3개**를 뽑습니다.
2. 보드의 **빈칸을 먼저 고른 뒤**, 뽑은 Emoji를 눌러 배치합니다.
3. 칸을 고르지 않은 상태에서 Emoji를 누르면 **능력 설명만** 보여줍니다.
4. 배치로 라인이 완성되면 그 라인의 Emoji 능력이 순서대로 발동합니다.
5. 쓰지 않은 Emoji는 버려지지만, **Pool은 줄어들지 않습니다.**

적도 같은 보드에 매 턴 1개씩 놓습니다.

### 빙고 규칙

| 규칙 | 내용 |
|---|---|
| 라인 | 가로 5 + 세로 5 + 대각선 2 = **총 12개** |
| 소유권 | 누가 많이 놓았는지와 무관하게 **마지막 칸을 채운 쪽**이 주인 |
| 효과 순서 | 가로 → 세로 → 대각선. 각 라인 안에서는 왼→오, 위→아래 |
| 다중 빙고 | 한 번에 N개 라인 완성 시 **각 라인의 수치가 N배** |
| 라인 제거 | 모든 효과 처리가 끝난 뒤 완성된 칸을 한 번에 비웁니다 |

전투는 양쪽이 3개씩, 총 6개의 Emoji가 미리 깔린 상태에서 시작합니다 (시작부터 빙고가 나지는 않습니다).

## 🗺️ 한 판(Run)의 흐름

```
타이틀 → 캐릭터 선택 → 난이도 선택 → Map 선택 → 전투 / 이벤트 / 휴식 → 보상 → ... → 결과
```

- **3 Stage × 10 Map**. Stage 3의 Boss를 잡으면 클리어, HP가 0이 되면 실패.
- Map을 하나 끝낼 때마다 **다음 후보 2개** 중 하나를 고릅니다. 전체 경로는 보이지 않습니다.
- 각 Stage의 **10번째 Map은 Boss로 고정**되고, 9번째 후보에는 최소 하나의 휴식이 있습니다.

| Map | 내용 |
|---|---|
| ⚔️ 일반 전투 | 기본 전투. 승리 시 보상 |
| 💀 Elite 전투 | 더 강한 적. 좋은 보상 확률이 높음 |
| ❓ 물음표 | 진입 시 이벤트 또는 전투로 결정 |
| 🔥 휴식 | 최대 HP의 30% 회복 |
| 👑 Boss | Stage 종료 전투 |
