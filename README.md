# 🎲 Bingoji

**Emoji 능력으로 싸우는 5×5 빙고 배틀 게임입니다.**
하나의 보드를 함께 채우고, 마지막 빈칸을 놓아 Bingo를 완성한 플레이어가 해당 Line의 모든 Emoji 효과를 사용합니다.

[🎮 Bingoji 플레이하기](https://jiwoong617.github.io/Bingoji/)

## 게임 소개

게임 시작 시 **싱글플레이**와 **멀티플레이** 중 하나를 선택할 수 있습니다.

### 싱글플레이

캐릭터와 난이도를 선택하고, 전투·이벤트·휴식을 거치며 Emoji Pool을 성장시키는 로그라이크 모드입니다. 세 Stage의 Boss를 모두 처치하면 승리합니다.

### 멀티플레이

Avatar, 닉네임과 Emoji Pool을 만든 뒤 방 코드로 다른 플레이어와 실시간 1:1 대전을 진행합니다. 두 플레이어는 같은 조건에서 시작하며 매 Turn 15초 안에 Emoji를 배치해야 합니다.

## 플레이 방법

1. Turn이 시작되면 내 Pool에서 Emoji 3개를 Draw합니다.
2. 빈칸을 선택하고 Draw한 Emoji 하나를 배치합니다.
3. Line을 완성하면 그 Line의 Emoji 효과가 순서대로 발동합니다.
4. 사용하지 않은 Emoji는 버려지지만 Pool에서는 사라지지 않습니다.
5. 상대의 HP를 먼저 0으로 만들면 승리합니다.

상대가 완성 직전까지 채운 Line도 마지막 한 칸을 놓으면 내 Bingo가 됩니다.
